# GitHub-hosted original strategy research
The continuous workflow uses GitHub-provided `windows-latest` workers, not the user's computer or a self-hosted runner. Windows preserves the supplied controller's real msvcrt locking and C:\\my\\bottest path semantics. Scheduling requests work every 15 minutes. GitHub execution delays, job time limits and interruption mean this is repeated research, not guaranteed uninterrupted service.
