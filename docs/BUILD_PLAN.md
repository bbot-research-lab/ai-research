# AI Research Lab — 구축 계획 (2026-10-14)

1. 기존 B-BOT 연구 ZIP의 코드·의존성·비밀정보 감사; 원본 ZIP 공개 금지.
2. 공식 연구 엔진 Linux 호환성 확보 및 단일 연구 dry-run 검증.
3. 유전 알고리즘과 Optuna를 후보 탐색에 추가; 기존 검증 기준 유지.
4. 백테스터의 봉인 미래 기간·시간순 가상매매·WF/OOS 검증 강화.
5. GitHub Actions 자동 반복 연구, 체크포인트/중복 방지 및 실패 복구.
6. AWS EC2가 매일 오전 6시(KST) 연구 결과만 pull, 출처·해시·버전 검증.
7. 단계적 승격(SHADOW→CANARY→SMALL→NORMAL) 및 자동 롤백 검증 후에만 실거래 적용 허용.
8. AWS 읽기 전용 텔레그램 비서: 보유 포지션, 수익, 실현손익, 거래 내역 자연어 질의 및 하루 1회 실거래 요약. 평소 알림은 검증 후 설정으로 끄고 주요 안전 경고는 유지.
9. 통합 테스트 및 회귀 검증.

## 불변 조건
- 재운게임즈 저장소/Actions, R4 실거래 주문·익절·청산 및 기존 포지션 관리 코드 변경 금지.
- 공개 저장소에 거래소 API 키, AWS/SSH 비밀키, 실거래 DB 및 개인 계좌 정보 업로드 금지.
- GitHub는 주문하지 않으며 실거래 서버 접속 권한을 갖지 않는다.
- GitHub Actions는 작업 사이 지연될 수 있으므로 24시간 무중단 실행은 보장하지 않는다.
- 연구 결과 검증 실패 시 실거래 설정 유지.

## 상태
계획 문서 등록 단계. 기존 연구 엔진, Actions 정기 스케줄, AWS 자동 수신, 텔레그램 비서 **미가동**.
